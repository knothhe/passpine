# Passpine 浏览器插件

WXT + Vite + TypeScript + React，使用 Radix Themes 可访问组件与 Lucide 图标。默认使用与客户端一致的黑白（monochrome）主题和图标，设置页可选择陶土橙风格，以及跟随系统 / 浅色 / 深色模式；不在扩展内嵌入 WebView 客户端，也不包含 Rust。

两套植物钥匙图标随主题风格切换：界面品牌和页签使用暖白底 / 陶土橙图形，或白底 / 黑色图形；浏览器工具栏保留主题色底 / 白色图形，黑白风格为黑底 / 白色图形。图标由客户端 `client/assets/generate.swift` 的矢量几何生成，包含 256px 界面资源与 16/32/48/128px 扩展资源；16px 版本简化枝叶细节。生成方式见 [应用图标说明](../client/assets/README.md)。

设置页「外观」中选择主题风格、明暗模式及文字大小（80%、90%、100%、110%、120%，默认 100%），自动保存到扩展本地存储，并实时更新已打开的弹窗和设置页；工具栏图标在后台启动及设置变化时同步更新。文字大小覆盖弹窗与设置页的文字，修改后立即更新当前已打开的扩展页面；弹窗保留 380×460 的尺寸，较大字号下内容在正文滚动。客户端和扩展分别保存外观与字号偏好，互不覆盖。主题使用现有 Radix `Theme` 的 `appearance`、`accentColor`、`grayColor`，由 `src/components/theme.css` 集中提供语义色彩；组件及 Radix 弹出层继承主题。陶土橙延续 Onevra，黑白参考 Racomi / Magpie 的中性灰表面并使用黑白主色。

## 开发与构建

使用 pnpm 12.11.2，扩展的 `pnpm-lock.yaml` 固定依赖，根目录锁文件固定包管理器自身；`packageManager` 在根目录和扩展包中声明同一版本。迁移前的 `package-lock.json` 已由 `pnpm import` 转换，日常开发不再运行 npm 安装。

```sh
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm test
make -C .. browser:build
pnpm run zip
```

[本地安装、配置与浏览器加载说明](../docs/install-local.md)

客户端设置 → 浏览器会检测已安装的浏览器，可逐项注册或修复本机 Native Messaging Host。扩展身份固定为：

- Native host：`com.knothhe.passpine`

Chrome manifest 的 `key` 是本仓库生成的公钥，仅用于固定开发版 ID；没有保留私钥。

## 独立交互预览

```sh
pnpm run preview
```

打开 `http://127.0.0.1:5174/`。这是显式 demo 入口，使用独立的虚构数据，不连接 Native Messaging，不读真实密码库。真实扩展的 entrypoints 不导入 demo client；连接失败时只呈现连接失败状态，不会回退到示例数据。

`/?view=options` 预览设置页。`style=onevra|monochrome` 和 `theme=system|light|dark` 可为预览指定初始外观，例如 `/?view=options&style=monochrome&theme=dark`；之后可直接操作设置页切换。预览外观独立保存到当前预览站点的 `localStorage`，不会修改已安装扩展的设置；不带参数重新打开时恢复上次预览外观。

独立 demo 在填充成功后保留弹窗，用于检查关联结果和错误状态；真实扩展弹窗会在网页填充成功后自动关闭。默认预览中，选择 Linear 等未匹配账号可直接填充并显示当前网站标记；在更多菜单或详情取消关联后标记消失，再次填充会重新关联。GitHub 初始匹配项也可取消关联。`/?fixture=rich` 提供长域名与长内容，初始没有匹配项，后续填充和关联会正常更新标记。`/?fixture=association-failure` 模拟填充成功但关联保存失败，选择未匹配账号可检查提示和关联状态；`/?fixture=fill-failure` 模拟网页无可填写表单，填充失败且不新增关联。这些状态仅存在于预览内存，刷新页面即重置，不实际填写网页或验证扩展存储。

## 组件边界

`src/components/AccountList.tsx` 负责可复用账号列表，`Primitives.tsx` 包含账号头像、操作按钮及凭证字段；`EditorForm.tsx`、`Generator.tsx`、`ConnectionState.tsx` 分别实现编辑、生成器和连接状态。`App.tsx` 负责弹窗状态与业务编排；`Options.tsx` 负责连接指引。新建、编辑和生成器直接在扩展弹窗内切换页面，使用统一导航、滚动内容和固定操作栏。列表去除品牌标题栏，域名旁放置图标新建按钮；密码库、连接状态、刷新、锁定及设置集中在底部。手动刷新立即显示旋转图标并禁用重复点击，完成后显示成功或失败结果。设置页采用有阅读宽度上限的响应式分区。

弹窗与旧插件一致固定为 380×460 CSS px，首帧占位与就绪状态尺寸一致。详情与列表共用 13px 主文字和 50px 信息行，填充、编辑与删除集中在顶部图标操作区；长字段省略并提供完整悬浮提示，展开的长密码和备注在正文滚动。生成器沿用客户端布局：单行密码预览和刷新、长度滑块与可输入数值、四类等宽字符按钮、排除混淆字符，支持 8–128 位；生成期间可继续调整，仅允许复制或使用最新选项对应的结果。

快捷键设置参考 Readomi 的键帽录制交互，支持 Esc 取消、Delete / Backspace 清除。弹窗快捷键可添加、删除并选择搜索、新建、刷新、锁定、设置、复制、填充或编辑操作，检测组合冲突并存储在扩展本地，已打开的弹窗实时更新。浏览器全局命令遵循浏览器限制：Firefox 可直接录制修改，Chromium 点击键帽跳转浏览器快捷键设置。

账号列表支持 `Ctrl+N` / `Ctrl+P` 和上下方向键选择条目。搜索框向下进入首项、向上进入末项，越过列表首尾返回搜索框；筛选结果沿用相同操作。点击条目正文或选中条目后按 Enter 均填充到当前网页，查看详情使用右侧详情图标。用户选择任意账号均可直接填充，成功后默认关联当前网站并自动关闭真实扩展弹窗，不等待列表刷新。关联保存失败但网页已填充时也会关闭；网页填充失败则保留弹窗显示错误，且不新增关联。再次打开弹窗可查看或取消当前网站关联。列表导航优先于相同的自定义弹窗快捷键，编辑表单和更多菜单保留自身的键盘操作。

列表采用连续排列的紧凑布局，网站路径在条目名称上方，当前网站匹配条目优先并显示行内标记，不额外分组。复制、刷新等操作结果及填充失败以内联反馈显示在底部状态区上方，不遮挡账号操作；真实扩展填充成功后直接关闭弹窗。每个条目依次提供用户名、密码、详情、更多操作，使用 Lucide 图标和当前主题色悬停效果。锁定时默认保留名称和本地搜索；显式读取、复制或填充会自动请求客户端的系统验证弹窗，成功后继续原操作。未配置系统解锁时会唤出客户端；名称列表和 OTP 定时刷新不会触发验证。

## 通信与安全边界

- 后台通过持久 `runtime.connectNative` Port 连接 Go host。`requestId` 关联并发响应，复用进程与本机连接。只合并在途 `configure` 请求；断线后拒绝所有在途请求，下次显式操作才重连。保存、删除、复制从不自动重放。
- 协议为 `{ protocol: 1, requestId, action, ... }`，返回 `{ protocol: 1, requestId, status, data, code?, message? }`。所有条目操作携带当前 `vaultId`；编辑和删除携带读取时的 `revision`，重命名使用原条目加 `destination`。
- 只允许正确扩展 ID 和精确 `popup.html` / `options.html` 地址发起内部请求；设置页允许浏览器标签页元数据。无后台响应、格式异常与真实协议版本差异分别报告，避免将连接失败误报为版本不一致。内容脚本和任意网页不能请求密码。
- 权限仅为 `activeTab`、`scripting`、`nativeMessaging`、`storage`、`clipboardWrite`。没有 `<all_urls>`、`tabs`、`clipboardRead` 或常驻注入脚本。
- 用户点击填充或使用快捷键后，后台核验活动 tab ID、完整 URL 与精确 hostname，再向顶层 frame 注入一次性填写函数；函数再次核验完整 URL。填充不要求已有网站关联，填写成功后才保存该账号与当前 hostname 的关联。不会自动提交表单，也不进入跨域 iframe。
- 系统验证期间暂停状态轮询，并将排队的元数据请求延后到验证结束。弹窗可见时每 2 秒读取轻量 status，只有 entriesVersion 改变才刷新完整列表。锁定、切库、断线或页面隐藏会清除详情与编辑状态；会话 epoch 和响应序号防止过期解密结果重新显示。OTP 到期先遮挡，再在仍打开的详情中刷新。
- 密码与私钥不写入浏览器持久存储。网站关联和取消关联仅以 vault/entry/hostname 组合的 SHA-256 摘要及状态存储；不使用远程 favicon 请求。条目复制由原生客户端操作剪贴板并按客户端设置清空。
- 独立生成器的「复制」使用浏览器剪贴板，生成值仅保存在打开的 UI 内存中，不会自动保存或自动清空剪贴板。

## 当前覆盖与限制

支持全库搜索、当前网站优先、锁定/断线状态、详情、用户名/密码/OTP 复制、生成密码、新建、编辑与改名、加密回收站删除、填充后自动关联、手动关联和取消关联、键盘快捷键和连接指引。关联按精确 hostname 匹配；取消关联也覆盖条目路径推导的默认匹配，之后再次成功填充会重新关联。保留编辑条目的自定义字段、OTP 配置与附加 URL。新增或改名的自定义字段不能占用用户名 / 网站别名及 note/notes；已有重复别名可保留并修改其值。

自动填充针对顶层页面中的标准 HTML 登录字段。跨域 iframe、Shadow DOM、自定义编辑器、HTTP Basic Auth 与通行密钥不在此版填充范围；可改用复制。回收站恢复、私钥管理与 Git 同步在原生客户端完成。默认不跨子域继承关联，在子域成功填充后会单独关联该子域。

视觉检查覆盖列表、详情、新建、编辑及错误、生成器、空库、空搜索、未配置、未连接、锁定、设置和确认框；补齐 Radix 弹出层的亮色 / 暗色主题变量，避免透明背景。

测试覆盖 Native Port 复用与断线不重放、发送者边界、协议字段白名单、域名伪装、路径验证、编辑保留字段、全库搜索，以及真实 DOM 的字段选择、事件触发、不提交和 URL/frame 核验。外观测试覆盖存储恢复与异常值、跨页面实时切换、系统明暗变化、图标 / 页签 / Radix 弹出层主题、保存失败，以及后台启动读取与后续设置更新的竞态。

验证边界：已运行 TypeScript 检查、纯逻辑/DOM 回归测试和 Chrome/Firefox 构建，并通过内置浏览器验收显式 demo 界面。尚未将扩展加载到用户的真实 Chrome/Firefox 配置进行完整 Native Messaging + 真实网站端到端验收。
