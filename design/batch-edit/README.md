# 批量整理交互原型

打开 `index.html` 体验多选、移动、修改文件夹前缀、同名冲突、回收站撤销及部分失败等状态；`canvas.html` 实时展示当前交互画板。两者支持 `?lang=en`，交互稿还支持 `?theme=dark`。

界面外观以当前桌面客户端为准：顶栏的密码库切换、Git 状态与同步，侧栏，以及条目列表和详情共用的内嵌卡片。

设计原则：已选数量下方并列“移动到”“修改前缀”“移到回收站”三个动作。“移动到”和“修改前缀”是平级入口，各自内容区拥有标题、配置和执行按钮；切换保留文件夹选择及前缀输入，进行中禁止切换。移动在右侧面板内完成，文件夹以缩进树形展示，不再弹窗。批量移到回收站先确认数量和本机加密恢复说明，取消保留选择；成功提供撤销，只有部分失败才保留结果页。

这是使用示例数据的交互原型，产品实现见 `client/desktop/batch.go` 与 `client/desktop/batch_prefix.go`。文件夹默认收起，所有含子目录的节点提供展开按钮；搜索与目标选择双向同步。`prefix.html` 展示原前缀单一候选的只读值与复制、新前缀编辑及处理数量汇总；`prefix-excluded.html` 展示多个原前缀候选、不修改原因及对应数量。预览保留处理总数，仅展示非零原因；“前缀不匹配”计数下列出每一项原始路径，缩进、弱色、每项一行并支持长路径换行，其它原因只显示计数。路径较多时仅滚动原因区域，字段和执行按钮保持可见。`prefix-no-folder.html` 展示没有可替换前缀的状态，`trash-confirm.html` 展示批量回收站确认。原前缀默认使用第一个已选条目的目录，候选包含所选目录及其祖先；只有多个候选时显示下拉。切换源前缀保留自定义新前缀草稿，新前缀不能为空。所有原型操作仅修改页面内的示例数据，不访问密码库、网络、剪贴板或客户端 API，复制按钮仅演示反馈，重新加载后恢复示例。

`constants/copy.ts` 为双语文案源，`constants/copy.js` 保持相同内容以便浏览器直接加载。画布直接加载各状态的 HTML，避免静态截图与当前交互不一致。
