# 批量整理交互原型

打开 `index.html` 体验多选、移动及保留原路径方式、同名冲突、回收站撤销及部分失败等状态；`canvas.html` 实时展示当前交互画板。两者支持 `?lang=en`，交互稿还支持 `?theme=dark`。

界面外观以当前桌面客户端为准：顶栏的密码库切换、Git 状态与同步，侧栏，以及条目列表和详情共用的内嵌卡片。

设计原则：移动与修改前缀合并为同一个移动表单，已选数量旁只保留“移到回收站”。表单自上而下为目标文件夹（缩进树形，可搜索或新建，不再弹窗）、保留原路径、路径预览，底部固定“移动 N 项”。保留原路径有三种方式，每项附当前选择中最深路径的示例：“去掉公共前缀”为默认，候选只包含所有已选条目共同的上级文件夹，默认最深一级，多个候选时显示下拉，替代原“修改前缀”；“完整路径”把原路径整体移入目标，例如 `test/a/b` 移到 `test0` 得到 `test0/test/a/b`；“仅条目名”得到 `test0/b`。所选条目没有共同上级时第一项禁用并说明原因，默认改为完整路径。切换方式或前缀只更新预览，不执行移动。预览逐项列出“原路径 → 新路径”，目标已存在、所选条目互相重名及路径不变的条目就地标注原因并排在最前，完成后保持选中；只有预览区滚动，执行按钮始终可见。批量移到回收站先确认数量和本机加密恢复说明，取消保留选择。

移动、回收站、清理空文件夹完成后，Toast 统一提供“撤销”，有效 8 秒。部分成功保留原失败结果和重试入口，同时可撤销本次已经完成的条目；重试成功也加入本次可撤销范围。点击撤销后，界面显示“正在撤销 n/N”，进度在完成前保持可见，也不允许重复操作。撤销不覆盖原路径已存在的条目，不恢复已被改动的目标；未完成部分保留为“已撤销 N 项，M 项未完成”，显示原因和“重试撤销”。关闭撤销结果返回原整理失败结果，原来的失败条目仍可重试。

撤销限定当前密码库和会话。新建文件夹、移动及其撤销只调整目录，不读取或改写条目内容，锁定时直接执行；仅当目标文件夹的 `.gpg-id` 收件人不同、需要重新加密时，才复用客户端解锁流程并在解锁后重试这些条目。回收站及其撤销需要认证时复用客户端解锁流程，说明“解锁后将撤销 N 项”，取消不丢弃待撤销内容；切换密码库或会话后旧入口失效。清理空文件夹撤销只重建本次实际删除的空目录，仍无需解锁。交互原型模拟数据恢复和冲突检查，不模拟真实认证或文件系统权限。`cleanup-success.html` 展示清理后的撤销提示，`undo-running.html` 展示进行中，`undo-partial.html` 展示原路径冲突与目标已更改的部分撤销；`success.html`、`trash.html`、`partial.html` 沿用原业务状态并补齐撤销入口。独立状态画板的提示保持显示以供审阅，交互中实际完成动作后的入口按 8 秒消失。

这是使用示例数据的交互原型，产品实现见 `client/desktop/batch.go`、`client/desktop/batch_move.go` 与 `client/desktop/batch_move_options.go`。文件夹默认收起，所有含子目录的节点提供展开按钮；搜索与目标选择双向同步。`move.html` 展示同一文件夹的条目移动，`strip.html` 展示去掉公共前缀并保留下级结构，`mixed.html` 展示没有共同上级时的禁用说明，`conflict.html` 展示仅条目名时的已存在与互相重名，`trash-confirm.html` 展示批量回收站确认。所有原型操作仅修改页面内的示例数据，不访问密码库、网络、剪贴板或客户端 API，重新加载后恢复示例。

`constants/copy.ts` 为双语文案源，`constants/copy.js` 保持相同内容以便浏览器直接加载。画布直接加载各状态的 HTML，避免静态截图与当前交互不一致。
