# 批量整理交互原型

打开 `index.html` 体验多选、移动、修改文件夹前缀、同名冲突、回收站撤销及部分失败等状态；`canvas.html` 实时展示当前交互画板。两者支持 `?lang=en`，交互稿还支持 `?theme=dark`。

界面外观以当前桌面客户端为准：顶栏的密码库切换、Git 状态与同步，侧栏，以及条目列表和详情共用的内嵌卡片。

设计原则：已选数量下方并列“移动到”“修改前缀”“移到回收站”三个动作。“移动到”和“修改前缀”是平级入口，各自内容区拥有标题、配置和执行按钮；切换保留文件夹选择及前缀输入，进行中禁止切换。移动在右侧面板内完成，文件夹以缩进树形展示，不再弹窗。“移动到”的目录搜索上方并列“保留前缀 / 不保留前缀”，默认保留完整原路径。例如 `test/a/b` 移动到 `test0` 得到 `test0/test/a/b`，不保留则得到 `test0/b`。切换选项仅更新预览和草稿，不执行移动。批量移到回收站先确认数量和本机加密恢复说明，取消保留选择。

移动、修改前缀、回收站、清理空文件夹完成后，Toast 统一提供“撤销”，有效 8 秒。部分成功保留原失败结果和重试入口，同时可撤销本次已经完成的条目；重试成功也加入本次可撤销范围。点击撤销后，界面显示“正在撤销 n/N”，进度在完成前保持可见，也不允许重复操作。撤销不覆盖原路径已存在的条目，不恢复已被改动的目标；未完成部分保留为“已撤销 N 项，M 项未完成”，显示原因和“重试撤销”。关闭撤销结果返回原整理失败结果，原来的失败条目仍可重试。

撤销限定当前密码库和会话。移动、前缀修改或回收站撤销需要认证时复用客户端解锁流程，说明“解锁后将撤销 N 项”，取消不丢弃待撤销内容；切换密码库或会话后旧入口失效。清理空文件夹撤销只重建本次实际删除的空目录，仍无需解锁。交互原型模拟数据恢复和冲突检查，不模拟真实认证或文件系统权限。`cleanup-success.html` 展示清理后的撤销提示，`undo-running.html` 展示进行中，`undo-partial.html` 展示原路径冲突与目标已更改的部分撤销；`success.html`、`trash.html`、`partial.html` 沿用原业务状态并补齐撤销入口。独立状态画板的提示保持显示以供审阅，交互中实际完成动作后的入口按 8 秒消失。

这是使用示例数据的交互原型，产品实现见 `client/desktop/batch.go` 与 `client/desktop/batch_prefix.go`。文件夹默认收起，所有含子目录的节点提供展开按钮；搜索与目标选择双向同步。`prefix.html` 展示原前缀单一候选的只读值与复制、新前缀编辑及处理数量汇总；`prefix-excluded.html` 展示多个原前缀候选、不修改原因及对应数量。预览保留处理总数，仅展示非零原因；“前缀不匹配”计数下列出每一项原始路径，缩进、弱色、每项一行并支持长路径换行，其它原因只显示计数。路径较多时仅滚动原因区域，字段和执行按钮保持可见。`prefix-no-folder.html` 展示没有可替换前缀的状态，`trash-confirm.html` 展示批量回收站确认。原前缀默认使用第一个已选条目的目录，候选包含所选目录及其祖先；只有多个候选时显示下拉。切换源前缀保留自定义新前缀草稿，新前缀不能为空。所有原型操作仅修改页面内的示例数据，不访问密码库、网络、剪贴板或客户端 API，复制按钮仅演示反馈，重新加载后恢复示例。

`constants/copy.ts` 为双语文案源，`constants/copy.js` 保持相同内容以便浏览器直接加载。画布直接加载各状态的 HTML，避免静态截图与当前交互不一致。
