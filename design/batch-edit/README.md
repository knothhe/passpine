# 批量整理交互原型

打开 `index.html` 体验多选、移动、同名冲突、回收站撤销及部分失败等状态；`canvas.html` 展示画板和验收截图。两者支持 `?lang=en`，交互稿还支持 `?theme=dark`。

界面外观以当前桌面客户端为准：顶栏的密码库切换、Git 状态与同步，侧栏，以及条目列表和详情共用的内嵌卡片。

设计原则：每个状态只说一件事，数量只出现一次。移动在右侧选择面板内完成，文件夹以缩进树形展示，不再弹窗。可恢复的操作（移到回收站）不确认，改为提供撤销；成功只用 Toast 反馈，只有部分失败才保留结果页。

这是尚未接入桌面客户端的设计原型。所有操作仅修改页面内的示例数据，不访问密码库、网络、剪贴板或客户端 API，重新加载后恢复示例。

`constants/copy.ts` 为双语文案源，`constants/copy.js` 保持相同内容以便浏览器直接加载；`evidence/` 保存对应状态的截图。
