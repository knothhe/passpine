# Passpine 隐私政策 / Privacy Policy

公开的隐私政策已发布在 **<https://passpine.knothhe.com/privacy>**，是浏览器扩展、桌面客户端和官网共用的唯一正文，中英文随访客语言切换，未执行 JavaScript 时也能读到预渲染的正文。2026-10-25 已验证匿名 HTTP 200 并填入 Chrome Web Store 草稿。

The public privacy policy is published at **<https://passpine.knothhe.com/privacy>**. It is the single source covering the browser extension, desktop client, and website, available in English and Simplified Chinese. Anonymous access and the saved dashboard URL were verified on 2026-10-25.

- 正文 / Text：[`website/src/constants/copy.ts`](../../website/src/constants/copy.ts) 中的 `privacy`
- 更新日期与核对版本 / Date and reviewed version：[`website/src/constants/routes.ts`](../../website/src/constants/routes.ts) 中的 `privacyPolicy`
- 后台填写参考与代码证据 / Dashboard answers and code evidence：[privacy-permissions.md](privacy-permissions.md)

数据处理方式变化时，同时修改两种语言的正文并更新日期，不在本目录另存一份副本，避免两处内容不一致。相比 0.1.2 草稿，当前政策补充了正式版客户端每日向 GitHub 检查更新、默认自动下载更新包，以及官网自身的数据处理。

2026-10-28 的仓库政策更新还披露了客户端保存网站关联、扩展缓存与 `alarms` 定期刷新，以及用户自行启用后的加密对象存储同步；旧版客户端仍使用浏览器本地关联记录。本次源码修改不代表公开政策或商店草稿已更新，部署及提交后需分别核对。

The 2026-10-28 source policy update also discloses client-owned website associations, extension caching and scheduled `alarms` refreshes, and encrypted object-storage sync when configured and enabled by the user. Older clients retain browser-local records. These source changes do not establish that the public policy or store draft has been updated; verify each after deployment or submission.
