## 名称

Passpine

## 短描述

将本机 Passpine 密码库安全连接到浏览器。

此字段来自包内 `_locales/zh_CN/messages.json` 的 `extensionDescription`，无需在后台另造一份不同描述。

## 详细介绍

Passpine 将本机密码库连接到 Chrome，让你在浏览器中查找账号、复制凭证并填写登录表单。

使用前需安装并运行 Passpine 桌面客户端，在客户端创建或打开密码库，并注册浏览器连接。首次使用无需准备 password-store 或 GPG 密钥：客户端可以创建兼容 pass 的密码库，并生成受口令保护的 OpenPGP 私钥。

主要功能：
• 搜索本地密码库，查看账号名称、用户名、密码、网站、备注及可用的一次性验证码；在新建或编辑界面维护自定义字段。
• 点击账号填写当前网页的用户名、密码及受支持的一次性验证码字段；填充不会自动提交表单。
• 将账号与当前网站关联，之后优先显示匹配账号；关联按精确主机名保存，不自动继承到其他子域名。
• 新建、编辑账号，在编辑表单内生成密码，将删除的账号移入客户端的加密回收站。
• 与客户端共用解锁会话；锁定后，可在支持并已配置的设备上进行系统验证，或前往客户端解锁。
• 支持 English、简体中文和跟随系统语言，可调整主题、明暗模式、文字大小与快捷键。

数据处理：扩展通过本机 Native Messaging 连接 Passpine 客户端，按你的操作读取或保存凭证。扩展读取当前标签页的网站地址来匹配账号，在你触发填充时检查登录输入框并将所选凭证交给当前网页。网站关联与扩展偏好保存在本机浏览器中。用户选择 Git 同步时，由桌面客户端连接用户配置的仓库；仓库中的条目内容经过 OpenPGP 加密，文件路径和 Git 元数据不因此隐藏。

使用限制：扩展不能单独作为密码库运行，需要保持客户端运行。浏览器内部页面、跨域 iframe、封闭的 Shadow DOM 及部分定制表单可能无法填充。请核对当前网站后再操作；HTTP 页面没有 HTTPS 的传输保护。系统解锁是否可用取决于操作系统与客户端配置。
