# 架构与通信

## 原生边界

桌面完全使用 Go 的 MyGo native UI，控件和 shell 来自 Onevra。系统菜单、托盘、窗口、文件选择与锁屏事件使用 MyGo API。剪贴板使用 MyGo 及平台敏感标记适配，macOS 直接通过 NSPasteboard 写入原始类型。Onevra 是 Go 原生库，不能直接运行在扩展中，因此浏览器复用 Radix Themes 控件并共享其视觉规范；账号列表、秘密字段、表单、生成器、状态组件单独封装。

密码库使用 ProtonMail 的 Go OpenPGP 实现；随机密码来自 `crypto/rand`。Git 调用系统二进制，禁用仓库 hooks 和 ext 协议，不在命令参数或日志里写私钥口令。应用自身不使用 Rust / Cargo。

主题风格与明暗外观分开管理。客户端通过 Shell 的 `Theme` 回调和 `Context.SetTheme` 向 MyGo / Onevra 控件提供集中式语义调色板，明暗继续使用 `mygo.Theme.SetSource`，保留系统文字缩放与高对比度设置。扩展通过 Radix `Theme` 的 `appearance`、`accentColor` 和 `grayColor`，配合集中的语义 CSS token，覆盖弹窗、设置页和弹出层。陶土橙保留 Onevra 配色；黑白采用 racomi / magpie 的冷灰基底与黑白主操作。主题及图标选择分别保存在客户端偏好与扩展本地存储中。扩展工具栏使用主题色底、白色图形，界面及客户端图标使用浅色底、主题色图形；错误、警告与成功仍使用语义提示色。

首次打开已有库时，默认从系统 GPG 自动导入：收集根目录和非隐藏子目录的 `.gpg-id`，通过系统 GPG 导出对应公钥，并在 Go 中校验匹配是否唯一，再按完整主钥指纹请求可导出的私钥。口令通过标准输入交给 GPG，导出仅在内存中传递。GPG 操作有超时和输出大小限制，保留 `GNUPGHOME`，不读取个人密钥文件格式。接口参考 [GnuPG 输入与输出文档](https://www.gnupg.org/documentation/manuals/gnupg/GPG-Input-and-Output.html)。

用户也可选择私钥文件和可选的补充公钥文件，直接由 Go 解析二进制或 ASCII armored OpenPGP 导出，无需系统 GPG。合并同一指纹的公私钥时保留私钥；补充公钥文件不能包含私钥。两种方式均验证所有现有密文、嵌套收件人策略及恢复记录，通过后才保存受口令保护的本机密钥副本。后续使用 Go 解锁与加解密；锁定期间结束的导入不能恢复会话。文件导入失败保留表单供重试，不会回退到系统 GPG；扩展不能提交密钥文件路径。

macOS 系统解锁由随应用签名的 Swift 辅助程序实现。默认开启，在支持 Secure Enclave 和系统用户验证的 Mac 上，首次用私钥口令解锁后请求系统验证，将口令封装为设备绑定的 P256 ECDH / HKDF-SHA256 / AES-GCM 密文。非永久设备密钥封装与密文保存在本机密钥目录，绑定当前密码库；真正的私钥运算由 `.userPresence` 强制执行 Touch ID 或 Mac 登录密码验证。登录密码由系统处理，应用不读取。辅助程序通过受限大小的标准输入 / 输出交换数据，锁定会取消验证，过期结果不能恢复会话。关闭系统解锁会删除所有密码库的设备封装；不支持的设备和验证失败时仍可使用私钥口令。

Windows 系统解锁使用客户端自身的独立辅助进程，通过 Windows 系统凭据对话框收集当前账户的登录密码，由 LogonUser 验证并核对 SID。登录密码经 scrypt 派生为 DPAPI 的附加熵，结合随机盐及当前密码库路径绑定，封装私钥口令；登录密码与派生密钥均不保存，使用后清理内存。辅助进程通过受限标准输入 / 输出交换数据，锁定、切库、关闭或超时会终止辅助进程；状态探测不弹出验证。Windows 登录密码变更后原封装失效，需关闭系统解锁、用私钥口令解锁后重新开启并注册；不支持用其他账户的凭据或 Windows Hello PIN 代替登录密码。

系统解锁已注册且保持开启时，客户端隐藏私钥口令输入。设备验证不可用时，可从安全设置关闭系统解锁后恢复私钥口令方式。

设置采用新默认值：锁定时允许列出条目名称、启用受支持的系统解锁；已有显式偏好保持不变。锁定状态仅提供路径元数据，详情、复制和填充仍要求解锁。设置、恢复与操作记录在主窗口内切换，顶部前进 / 后退保留搜索、账号选择和未保存编辑；新建与编辑使用右侧详情区域。时间参数由分段选择器提供三个档位，已有自定义时长替换一个常用档位以保留当前值。语言默认跟随系统，支持 `en` / `zh-CN`，未匹配时回退英文，语言切换不修改密码库内容。操作记录按条数和年龄同时清理，默认 1000 条 / 7 天，关闭记录也继续清理已有记录。设置更改自动合并保存；Git 远端在停止输入后保存，不触发网络同步。复制、保存、提示与错误共用窗口浮层，不改变内容布局。

全局快捷键打开独立的原生 Panel，不改变主窗口导航或编辑状态。面板使用与主窗口相同的组件和不透明配色，在当前屏幕上部居中首次展示；客户端在应用数据目录中独立保存拖动位置，恢复时校正到已连接显示器的可用区域。搜索仅使用条目元数据，复制沿用服务的剪贴板会话校验，锁定后必须在面板内验证或进入主窗口解锁。

## 持久通信

```text
Popup / Options
    │ 扩展内部消息（校验 sender 与具体入口）
Background service worker
    │ runtime.connectNative，持久 Port
Go passpine-host
    │ 带随机 token 的持久 loopback TCP，非 HTTP
Go app.Service
    │ 同一个 vault.Vault 解锁会话
OpenPGP 密码库
```

- 消息为 UTF-8 JSON，4 字节 little-endian 长度前缀，上限 1 MiB。JSON 易调试，凭证消息很小，避免额外 schema 编译和迁移成本。
- 所有消息携带协议版本 1 和 `requestId`。原生进程复用，Host 复用本机连接；空闲连接在下一次请求前主动更新，避免首次使用遇到已过期连接。
- 任意条目操作都携带当前 `vaultId`；写入 / 删除携带密文 SHA-256 `revision`，重命名加 `destination`。切库或内容变化会拒绝旧请求。
- `configure` / `list` 返回路径元数据；`status` 为轻量状态。`fetch` 选中后才解密，`copy` 由客户端执行。普通操作响应不重复发送完整列表。
- 客户端缓存路径元数据 2 秒，自己的写入立即使缓存失效。`entriesVersion` 变化通知浏览器重新取得完整列表；浏览器只在 popup 可见期间每 2 秒检查轻状态。
- UI 搜索在本地进行，原生列表虚拟化、查询结果缓存。OTP 从已解密详情在本地更新，扩展到期后才刷新。
- 断线拒绝在途请求，新请求重新连接；**不会自动重放写入或删除**。超时之后应刷新确认写入结果，不能假设操作一定未完成。

## 权限与会话

Host 验证固定扩展 origin / Firefox ID；只读取权限为 0600、当前用户拥有的 endpoint 文件。监听随机本机端口，消息还需通过 256-bit 随机 token 验证。端口不提供 HTTP 或 CORS 服务，网页不能调用凭证接口。应用目录为 0700。

浏览器显式查看、复制、填充或解锁可请求系统验证弹窗；只有开启系统解锁且已有设备封装时自动执行，成功后继续原操作。未就绪时唤出客户端，元数据读取与 OTP 定时刷新不会触发验证。交互请求绑定到达时的取消代数，认证后先取得新会话的响应凭证再读取秘密，排队期间锁定或切库会拒绝旧操作。系统验证等待最多两分钟，Host 保留 130 秒响应窗口，元数据短超时在认证结束后开始。

浏览器只允许 popup / options 请求凭证；没有常驻内容脚本或全站读取权限。用户选择任意账号均可填充，不要求预先关联网站。填充前检查当前 tab、完整 URL、精确 hostname 和顶层 frame；注入后再次检查，不自动提交，不跨域 iframe 填充。只有成功填写后才自动关联账号与当前 hostname，填充失败不新增关联；关联写入失败单独返回未保存状态，保留填充成功结果。关联和取消关联只持久保存 vault/entry/hostname 的 SHA-256 摘要及状态，取消关联覆盖条目路径的默认匹配，再次成功填充可恢复关联。

锁定使私钥引用和会话代数失效；后台到期计时器独立于用户请求。空闲与最长会话到期统一由共享 `vault.Vault` 判断，桌面只同步其锁定结果；浏览器重新认证后使用新会话的起点，桌面旧活动时间不会提前锁定新会话。写操作在提交前重查会话，前端丢弃旧代响应；剪贴板写入在 UI 线程执行时再次检查会话。锁定 / 切库 / 断线清除扩展详情及未保存编辑状态。浏览器不持久保存私钥、密码或解密正文。

密码、验证码、完整条目和自定义字段复制时，文本与敏感标记一起写入剪贴板。macOS 添加 `org.nspasteboard.ConcealedType` 和 `org.nspasteboard.TransientType`，不另外限制通用剪贴板；Windows 添加系统剪贴板历史与云同步排除格式；Linux 添加 `x-kde-passwordManagerHint=secret`。用户名使用普通文本。标记是否被第三方剪贴板管理器遵守取决于其实现，客户端仍按配置自动清空尚未被替换的内容。

扩展独立生成器通过 `copy-generated` 请求原生客户端复制当前生成的密码，使用同样的敏感标记和清空时间。它与生成操作一样不要求配置或解锁密码库，但在应用关闭或请求期间发生锁定、切库等取消事件后拒绝晚到写入。浏览器预览仍使用演示剪贴板路径；扩展 ID 等普通内容直接使用浏览器剪贴板。

Go GC、字符串和第三方密钥结构不提供物理内存零化保证，因此不承诺锁定后进程内每个历史字节均已擦除。敏感内容不写入明文临时文件或操作日志。

## 文件与恢复

文件操作逐级检查路径，拒绝符号链接、路径穿越和保留名；使用 no-follow 文件描述符、受限权限、同步写入和跨进程文件锁。普通单路径更新采用加密临时文件替换。

重命名先持久化目标密文，再删除源文件。目标目录按当前 `.gpg-id` 重新加密；崩溃窗口可能保留两份加密副本，优先避免丢失数据，并非跨两路径的文件系统事务。

草稿 / 回收站将路径、正文、原 revision 等一起加密后保存在密钥目录。写入或删除源条目前，先验证新密文可由本机现有私钥解密；导入替换密钥和验证恢复备份也覆盖所有草稿 / 回收站记录，避免部分子钥或旧备份使恢复副本失效。恢复不覆盖已有条目，并按目标当前收件人重加密。永久删除需要界面确认。私钥和恢复目录必须位于密码库之外。

Git 只暂存 `.gpg` 和 `.gpg-id`，使用 literal pathspec 避免名称中的通配符选中无关文件，拒绝用户已有的暂存变更和未完成的合并 / rebase。网络同步使用独立锁，读取可继续，写入遇文件锁立即报告 busy。Git 操作与解锁会话分开，锁定不会取消同步，切换密码库或关闭应用才取消该库的 Git 进程。仓库本地状态每 5 秒异步刷新并缓存，包含分支、远端跟踪、变更、领先 / 落后提交、同步进度、错误和最近结果；状态读取不访问网络，也不由自动同步开关控制。自动同步开关只控制变更后和定时后台同步，锁定期间也可运行。网络操作使用单独的 UI 请求通道，不阻止浏览和解密。冲突保留现场供用户处理，不强制覆盖或自动丢弃修改。
