# 架构与通信

## 原生边界

桌面完全使用 Go 的 MyGo native UI，控件和 shell 来自 Onevra。系统菜单、托盘、窗口、剪贴板、文件选择与锁屏事件使用 MyGo API。Onevra 是 Go 原生库，不能直接运行在扩展中，因此浏览器复用 Radix Themes 控件并共享其视觉规范；账号列表、秘密字段、表单、生成器、状态组件单独封装。

密码库使用 ProtonMail 的 Go OpenPGP 实现；随机密码来自 `crypto/rand`。Git 调用系统二进制，禁用仓库 hooks 和 ext 协议，不在命令参数或日志里写私钥口令。应用自身不使用 Rust / Cargo。

## 持久通信

```text
Popup / Options
    │ 扩展内部消息（校验 sender 与具体入口）
Background service worker
    │ runtime.connectNative，持久 Port
Go passpine-host
    │ 带随机 token 的持久 loopback TCP，非 HTTP
Go app.Service
    │ 同一个 vault.Vault 解锁会话
OpenPGP 密码库
```

- 消息为 UTF-8 JSON，4 字节 little-endian 长度前缀，上限 1 MiB。JSON 易调试，凭证消息很小，避免额外 schema 编译和迁移成本。
- 所有消息携带协议版本 1 和 `requestId`。原生进程复用，Host 复用本机连接；空闲连接在下一次请求前主动更新，避免首次使用遇到已过期连接。
- 任意条目操作都携带当前 `vaultId`；写入 / 删除携带密文 SHA-256 `revision`，重命名加 `destination`。切库或内容变化会拒绝旧请求。
- `configure` / `list` 返回路径元数据；`status` 为轻量状态。`fetch` 选中后才解密，`copy` 由客户端执行。普通操作响应不重复发送完整列表。
- 客户端缓存路径元数据 2 秒，自己的写入立即使缓存失效。`entriesVersion` 变化通知浏览器重新取得完整列表；浏览器只在 popup 可见期间每 2 秒检查轻状态。
- UI 搜索在本地进行，原生列表虚拟化、查询结果缓存。OTP 从已解密详情在本地更新，扩展到期后才刷新。
- 断线拒绝在途请求，新请求重新连接；**不会自动重放写入或删除**。超时之后应刷新确认写入结果，不能假设操作一定未完成。

## 权限与会话

Host 验证固定扩展 origin / Firefox ID；只读取权限为 0600、当前用户拥有的 endpoint 文件。监听随机本机端口，消息还需通过 256-bit 随机 token 验证。端口不提供 HTTP 或 CORS 服务，网页不能调用凭证接口。应用目录为 0700。

浏览器只允许 popup / options 请求凭证；没有常驻内容脚本或全站读取权限。填充前检查当前 tab、完整 URL、精确网站关联和顶层 frame；注入后再次检查，不自动提交。不会跨域 iframe 填充。

锁定使私钥引用和会话代数失效；后台到期计时器独立于用户请求。写操作在提交前重查会话，前端丢弃旧代响应；剪贴板写入在 UI 线程执行时再次检查会话。锁定 / 切库 / 断线清除扩展详情及未保存编辑状态。浏览器不持久保存私钥、密码或解密正文。

Go GC、字符串和第三方密钥结构不提供物理内存零化保证，因此不承诺锁定后进程内每个历史字节均已擦除。敏感内容不写入明文临时文件或操作日志。

## 文件与恢复

文件操作逐级检查路径，拒绝符号链接、路径穿越和保留名；使用 no-follow 文件描述符、受限权限、同步写入和跨进程文件锁。普通单路径更新采用加密临时文件替换。

重命名先持久化目标密文，再删除源文件。目标目录按当前 `.gpg-id` 重新加密；崩溃窗口可能保留两份加密副本，优先避免丢失数据，并非跨两路径的文件系统事务。

草稿 / 回收站将路径、正文、原 revision 等一起加密后保存在密钥目录。写入或删除源条目前，先验证新密文可由本机现有私钥解密；导入替换密钥和验证恢复备份也覆盖所有草稿 / 回收站记录，避免部分子钥或旧备份使恢复副本失效。恢复不覆盖已有条目，并按目标当前收件人重加密。永久删除需要界面确认。私钥和恢复目录必须位于密码库之外。

Git 只暂存 `.gpg` 和 `.gpg-id`，使用 literal pathspec 避免名称中的通配符选中无关文件，拒绝用户已有的暂存变更和未完成的合并 / rebase。网络同步使用独立锁，读取可继续，写入遇文件锁立即报告 busy。锁定取消 Git 命令及子进程。冲突保留现场供用户处理，不强制覆盖或自动丢弃修改。
