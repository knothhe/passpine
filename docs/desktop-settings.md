# 桌面设置与生命周期

窗口和启动相关选项位于客户端设置 → **通用**中的**窗口与启动**分组，包含 Dock 图标、点击托盘图标、轻量模式和开机自启，修改后自动保存。新配置默认显示 Dock 图标、托盘点击打开快捷面板，轻量模式和开机自启默认关闭。两端的默认主题与图标均为黑白（monochrome）；已保存的主题选择继续保留。客户端与扩展分别保存外观偏好。

客户端设置中的开启 / 关闭选项统一使用两段分段选择器，包含关闭窗口后继续运行、本机操作记录、轻量模式、开机自启、系统解锁、锁定时浏览名称和 Git 自动同步。所选段表示当前值，修改后自动保存；不可用的系统解锁或预览模式中的开机自启会禁用选择。Dock 图标的展示 / 隐藏 / 跟随窗口、点击托盘图标的快捷面板 / 主窗口也使用分段选择器。

## 外观与文字大小

文字大小位于设置 → **通用**的外观选项，提供 **80%、90%、100%、110%、120%** 五段，默认 **100%**。桌面基础字号为 12px；主窗口、托盘快捷面板与全局搜索的标题、条目、辅助文字和输入文字随所选比例一起调整，并继续尊重系统文字大小和辅助功能偏好。修改后立即生效并自动保存。

黑白主题采用参考 Magpie 桌面面板的中性灰表面，深色界面使用柔和的灰色底板与较深的卡片 / 输入区域，浅色界面使用浅灰底板与白色卡片。主操作在深色界面使用浅色按钮和深色文字，在浅色界面使用深色按钮和白色文字；按钮内的回车图标保持完整前景色。

客户端与浏览器扩展分别保存文字大小，调整一端不会改动另一端。扩展设置 → **外观**提供相同五段选项，作用于扩展弹窗和设置页，并同步到当前已打开的扩展页面。浏览器缩放和客户端文字大小是各自独立的设置。

## Dock 与托盘

Dock 图标有三个选项：

- **展示**：应用运行时显示图标。
- **隐藏**：应用保持运行，通过菜单栏 / 托盘或全局快捷键打开。
- **跟随窗口**：主窗口打开时显示，主窗口关闭后隐藏；快捷面板不影响 Dock 图标。

托盘点击可选择**打开快捷面板**或**打开主窗口**。快捷面板在托盘图标下方展开，正文用于查询密码条目与复制密码，条目编辑与恢复管理在主窗口完成；点击面板外部会收起。靠近屏幕边缘时自动调整位置，避免超出可用屏幕。

全局搜索仍是独立的浮动搜索框，快捷键默认为 `Control+Option+Space`，保留可拖动和记住位置的行为。托盘面板不会覆盖全局搜索的位置。两者遵循“锁定时列出名称”，复制秘密时沿用系统验证，成功后继续原操作。

`Command+W` 关闭当前窗口，也可通过菜单 **窗口 → 关闭窗口** 触发。主窗口沿用关闭按钮的行为：先处理生成器、编辑器和未保存内容，再按“关闭窗口后继续运行”设置关闭或收起到托盘。快捷面板与全局搜索只收起自身。

快捷面板与全局搜索在 Passpine 名称旁提供 Esc 关闭入口，右上角依次提供**刷新条目**、**打开主窗口**、**打开设置**三个图标。刷新会重新扫描当前密码库的本地条目，显示进行中和完成 / 失败反馈，并保留当前搜索；不会执行 Git 同步或触发认证。顶部“打开主窗口”只唤起主窗口，保留其当前页面、查询和未保存的编辑；“打开设置”唤起主窗口并进入设置页。全局搜索底部的原“打开主窗口”入口与 `Command+O` 仍会把当前搜索和选中条目带到主窗口。密码库名称较长时省略显示，悬浮可查看完整名称。

## 轻量模式

开启轻量模式且关闭主窗口和快捷面板后，等待 1 分钟再释放可重建的窗口、界面与条目展示缓存；保留托盘、浏览器所需的本机服务、密码库会话管理与唤醒能力。计时期间重新打开任意窗口会取消本次释放，再次关闭时重新计时。

释放后再次打开窗口会重建界面，向保留的本机服务重新读取状态与条目，并按需加载详情；密码库会话继续遵守既有锁定和验证规则。内存释放不等于退出应用；浏览器连接和唤醒入口仍可用。进程最终驻留大小受 Go 运行时、原生图形资源和系统回收影响，不保证固定内存值。若关闭“关闭窗口后继续运行”，关闭主窗口会按退出设置处理。

## 开机自启

macOS 可在设置中启用或关闭开机自启，登录时启动当前应用。推荐先安装到固定的应用目录（正式版为 `~/Applications/Passpine.app`，Dev 为 `~/Applications/Passpine Dev.app`），再启用；移动或重新安装到其他位置后重新开启以更新路径。登录启动继续遵守原有锁定策略，不自动提供私钥口令或跳过系统验证。其他平台支持情况以设置页反馈和目标系统验证为准。

## 页面与提示

页面前进、后退和切换使用短过渡动画，保留已有导航历史、搜索与表单状态。操作结果的倒计时依据实际经过时间计算，切换焦点不会让提示一直停留；重新聚焦时不会恢复已过期的提示。

## 关于

设置 → **关于**（macOS 也可使用 Passpine 菜单 → **关于**）显示当前客户端版本和六项主要直接依赖。点击组件名称可展开精确版本、包名、用途、许可证、文档与源代码链接；不展示浏览器依赖、开发工具或间接依赖。尚未打开密码库时也可查看。

依赖版本从 `client/go.mod` 同步；构建和开发入口自动更新目录，检查脚本会拒绝过期信息。单独更新依赖后可运行 `pnpm run about:generate`。正式构建显示项目版本，本地 Make Dev 构建显示带 `-dev.<提交>` 的版本；`pnpm run dev`、`pnpm run preview` 和直接运行 Go 源码均使用 Dev 通道。直接运行未注入版本的 Go 二进制时显示“开发版本”。

检测到 Omarchy 当前主题时，新安装客户端默认选择「Omarchy 系统配色」，已有明确主题选择会保留。macOS / Windows 不显示此选项，导入的不适用配置会回退到黑白主题。Linux 原生菜单栏及弹出菜单跟随应用配色。

Linux 客户端的「Omarchy 系统配色」主题风格读取 `$XDG_STATE_HOME/omarchy/current/theme/colors.toml`（默认 `~/.local/state/omarchy/current/theme/colors.toml`），兼容旧版 `$XDG_CONFIG_HOME/omarchy/current/theme/colors.toml`，并自动检测主题切换。「跟随系统」使用该主题的深浅配色；手动选择浅色或深色时保留外观设置，并使用 Omarchy 强调色。配置缺失或颜色无效时回退到黑白主题，不修改系统配置。其他平台不显示此选项。

Linux 的「使用系统验证解锁」需要 PAM、系统 `login` 策略及图形 Pinentry。启用后先用私钥口令解锁一次，再在系统密码框中输入本机 Linux 登录密码完成注册；之后每次系统解锁都会验证登录密码。取消时仍保持锁定。登录密码变更后，在安全设置中关闭系统解锁，使用私钥口令解锁，再重新开启并注册。

## 软件更新

设置 → **软件更新** 提供当前版本、下载进度和失败重试。自动下载默认开启，关闭后仍在启动及运行期间自动检查，改为等待手动下载。更新始终下载完整包；下载完成不会退出应用。

「更新说明」显示为整条可点击的链接行，打开对应 GitHub Release，不在设置页内嵌正文。链接优先指向有效的稳定候选版本，否则指向当前稳定版本；没有稳定版本时禁用。链接标题、说明和不可用状态均支持中英文，GitHub Release 正文保留发布页面内容。

点击「重启并安装」后再次确认；未保存的编辑和正在进行的操作会阻止重启。确认后等待已开始的客户端、浏览器与 Git 请求完成，再次校验更新包并启动安装助手。安装失败会保留或恢复原版本与用户数据。开发构建、预览模式和未配置签名公钥的构建不自动更新。签名配置及发布流程见[客户端自动更新](updates.md)。
